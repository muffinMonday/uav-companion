# Motor Diagnostics: Hazard Analysis

**Status:** Draft, 2026-11-16. **Mandatory Phase 3 entry gate** of the [consolidated backlog](backlogs/in-progress/UAV_COMPANION_AUTOMATED_MOTOR_DIAGNOSTICS_BACKLOG.md) (section 24). Documentation only; it authorizes nothing. Phase 3 must not start until the owner reviews it and every row has a passing verification plan.
**Conventions:** "Stop" means external value 1000 plus the four-part stop proof (repeated 1000, FC read-back of 1000 for every enabled motor, valid RPM zero for the observation period, user confirmation that no motor is rotating). All timings are provisional. Tests marked *mock* run on a mocked transport; tests marked *HW* need supervised hardware and are unverified today.

| ID | Hazard | Initiating failure | Mitigation | Detection | Recovery | Verification test |
| --- | --- | --- | --- | --- | --- | --- |
| H1 | Unexpected motor rotation (wrong motor, rotation at idle, creeping) | Mapping or mixer mismatch; ESC fault; noise on the signal line; software defect | One motor at a time; cap 1100; identity check on the first low-output test of each output; hold-to-start; nonzero only in `RUNNING` | Peer-motor RPM nonzero; RPM at powered-zero; user-selected spun motor differs from expected | Immediate Stop; lock; battery removal, reconnect, safe-state, powered-zero verification before any new test | *mock*: peer RPM injected in every state locks and stops. *mock*: identity mismatch locks. *HW*: wrong-order mixer on a bench rig. Static test: `MSP_SET_MOTOR` reachable only from `RUNNING` |
| H2 | Propellers fitted during a test | User skips or misreads the removal step; propeller refitted after the checklist | Fresh per-item acknowledgement plus press-and-hold; acknowledgement expires on reload, reconnect and fault; cap 1100 limits thrust; smoke stopper and accessible battery plug required | RPM or current implausibly high for the commanded value (secondary warning only; never replaces the physical confirmation) | Stop; require battery removal; restart the checklist | *mock*: expiry on reload, reconnect and fault. *mock*: implausible-RPM warning raised. *HW*: measure unloaded versus loaded RPM and current on a non-flying rig (M1) |
| H3 | Battery or smoke-stopper fault (short, stopper trips, sag, loose connector, thermal event) | Wiring fault, ESC failure, damaged battery | Smoke stopper or current limiter required; battery plug within reach; bench on a nonconductive surface; low output cap | Voltage drop or fault, ESC temperature limit, telemetry loss, MSP voltage anomaly; user observation of smoke or smell | Disconnect the battery by hand first (the guaranteed action); then Stop and lock; never reconnect before inspection | *mock*: voltage fault and over-temperature lock. *HW*: smoke-stopper behaviour with a controlled load; physical disconnect drill timed |
| H4 | USB or serial loss while powered | Cable, port, host power or FC reset; transport error | State machine locks on any transport error; the FC holds the last command (F1, F2), so the screen leads with **Disconnect the flight battery now.** | Port `disconnect` event; ACK timeout twice in a row (150 ms each, provisional); frame errors | Battery removal; FC reconnect; repeat safe-state and powered-zero verification | *mock*: disconnect in every state, with output nonzero. *HW*: USB removal during every bench state including nonzero output (backlog hardware matrix) |
| H5 | Browser loss, suspension or frozen execution (tab closed, crash, OS kill, page frozen, Android swipe-away, screen lock) | Page lifecycle events; memory pressure; user action | A hidden page is a fault: attempt Stop at once where execution survives, never claimed as guaranteed (F22); `UNCLEAN_EXIT_RECOVERY` marker set durably before battery connection; Stop sent on every new FC session; navigation interception where the platform permits | On reload: marker present; `visibilitychange` hidden; `freeze` | On next load: treat battery state as unknown, lead with the battery instruction, full recovery sequence; marker cleared only after the four stop conditions and confirmed removal | *mock*: reload with marker present; storage unavailable blocks powered testing; unverifiable marker write blocks. *HW*: swipe-away, lock, shade, app-switch behaviour per phone (M8); app termination recovery |
| H6 | Stale or absent telemetry | Polling stall; RPM channel failure; build without stats; USB congestion | Fail closed: stale or unavailable RPM in a powered session fails the stop proof and requires battery disconnection; no nonzero step without fresh valid RPM | No valid telemetry for 200 ms (provisional); parser flags `invalidPct` of 100% as error data unavailable | Stop; lock; battery disconnection | *mock*: telemetry dropout in every state; stale telemetry never accepted as zero. *HW*: measure poll rate and dropout (M4) |
| H7 | Retained nonzero motor command | Zero command not delivered; FC keeps `motor_disarmed` until changed or reboot (F1, F2); ESC ignores 1000 | Repeated external 1000 (50 ms cadence, at least 10); FC read-back of 1000 for every enabled motor; valid RPM zero; user visual confirmation; read-back alone never sufficient (F3) | Read-back not 1000; RPM nonzero; user reports rotation | Keep resending; if proof does not complete, lock and require battery disconnection; no normal exit | *mock*: read-back stuck at nonzero, RPM nonzero, user denies. *mock*: stop never accepted on read-back alone. *HW*: confirm external 1000 stops each ESC family on the five aircraft |
| H8 | Arm switch or arming state changes during a test | Transmitter switch on; receiver failsafe; FC arms | Gate requires `ARMED` false, ARM box inactive, user attestation; arming change is a Category 1 stop | `MSP_STATUS_EX` armed flag and box flags (ARM bit still to confirm in Phase 1) | Stop; lock; recovery sequence | *mock*: armed flag in every state. *HW*: arm bit identification per tag |
| H9 | Unsupported or misidentified firmware | Allowlist wrong; build reports a different API minor than its tag | Exact version and API pair allowlist; unknown fails closed; candidates are not supported until hardware-checked | Version and API mismatch; unknown response | Block with the detected and required values; no motor capability | *mock*: unknown firmware, API and response fail closed. *HW*: real API minor per aircraft (inventory) |
| H10 | Logging configuration wrong (mode `NORMAL`, fields disabled) | Misconfiguration; attestation incorrect | Mode gate (`MOTOR_TEST` or `ALWAYS`); field-mask gate; log content checked afterward | Gate values; empty or missing segment | Block or mark the sweep unavailable; manual Betaflight steps; never changed by the app | *mock*: mask and mode combinations. Open: production mode gating pending RQ-1 |

## Not covered by software

Physical hazards that software cannot remove: the battery plug is the only guaranteed emergency action; an operator who ignores on-screen instructions; mechanical failure of a motor on a bench; ESC or battery thermal events. These stay in the instructions shown before testing and in the final report.
